# PRODUCT CONTEXT: AWGEINMISE MUSIC COLLECTIVE

## ПРОДУКТОВАЯ СТРАТЕГИЯ
**Миссия:** Создание платформы для продвижения талантов музыкального коллектива AWGEINMISE  
**Видение:** Стать узнаваемым брендом в русскоязычной хип-хоп сцене  

## ОСНОВНЫЕ ПРОДУКТОВЫЕ СЦЕНАРИИ

### 1. ПОТРЕБЛЕНИЕ КОНТЕНТА
- **Слушатель заходит послушать музыку**
  - Переходит в раздел "Музыка" 
  - Выбирает трек из плейлиста
  - Слушает через встроенный плеер
  - Может скачать понравившийся трек

### 2. ПОИСК БИТОВ ДЛЯ ТВОРЧЕСТВА
- **Артист ищет биты для записи**
  - Переходит в раздел битов
  - Прослушивает доступные биты
  - Выбирает подходящий по стилю и BPM
  - Скачивает для использования

### 3. ЗНАКОМСТВО С АРТИСТАМИ
- **Новый слушатель изучает коллектив**
  - Просматривает галерею артистов
  - Читает информацию о каждом участнике
  - Переходит к прослушиванию их треков
  - Подписывается в социальных сетях

## ПОЛЬЗОВАТЕЛЬСКИЕ ПЕРСОНЫ

### Основная аудитория (70%)
- **Возраст:** 16-25 лет
- **Интересы:** Хип-хоп, рэп, российская музыка
- **Поведение:** Активно используют соцсети, слушают музыку онлайн
- **Мотивация:** Поиск новой музыки, поддержка андеграунд артистов

### Создатели контента (20%)
- **Возраст:** 18-30 лет
- **Интересы:** Создание музыки, битмейкинг
- **Поведение:** Ищут качественные биты для треков
- **Мотивация:** Создание собственных треков

### Музыкальная индустрия (10%)
- **Возраст:** 25-40 лет
- **Интересы:** Поиск новых талантов, сотрудничество
- **Поведение:** Профессиональная деятельность в музыке
- **Мотивация:** Бизнес возможности, коллаборации

## КЛЮЧЕВЫЕ МЕТРИКИ

### Engagement метрики
- Время на сайте (цель: >3 минуты)
- Количество прослушанных треков за сессию (цель: >2)
- Процент возвратов (цель: >30%)

### Контентные метрики
- Количество скачиваний треков
- Количество прослушиваний битов
- Переходы в социальные сети

### Технические метрики
- Скорость загрузки страниц (<3 сек)
- Мобильная оптимизация (>95% Lighthouse)
- Кроссбраузерная совместимость
