# PROJECT BRIEF: AWGEINMISE MUSIC COLLECTIVE WEBSITE

## PROJECT OVERVIEW
**Название проекта:** AWGEINMISE Music Collective  
**Тип проекта:** Веб-сайт музыкального коллектива  
**Платформа:** Web (HTML, CSS, JavaScript)  
**Статус:** Активный проект  

## ОПИСАНИЕ ПРОЕКТА
Официальный веб-сайт музыкального коллектива AWGEINMISE, представляющий артистов, их музыку и биты.

## ТЕКУЩАЯ СТРУКТУРА
- **Главная страница:** index.html (с фоновым видео и логотипом)
- **Музыка:** music.html (плеер с треками артистов)
- **Артисты:** artists.html (галерея артистов)
- **Контакты:** contacts.html (социальные сети)
- **Работа:** work.html (информация о работе)

## ОСНОВНЫЕ ФУНКЦИИ
1. Музыкальный плеер с треками артистов коллектива
2. Галерея артистов с их фотографиями
3. Коллекция битов для использования
4. Интеграция с социальными сетями (VK, Telegram, YouTube)
5. Адаптивный дизайн для мобильных устройств

## ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ
- **Frontend:** Vanilla HTML, CSS, JavaScript
- **Медиафайлы:** MP3 аудио, MP4 видео, JPG изображения, SVG иконки
- **Развертывание:** FTP (есть скрипт upload.ps1)
- **Управление зависимостями:** package.json (Node.js экосистема)

## КЛЮЧЕВЫЕ ОСОБЕННОСТИ
- Дождь из логотипов на главной странице
- Фоновое видео
- Кастомный музыкальный виджет
- Адаптивная мобильная версия
- Система загрузки на сервер через FTP

## ЦЕЛИ ПРОЕКТА
- Продвижение музыкального коллектива
- Демонстрация творчества артистов
- Предоставление битов для использования
- Привлечение новой аудитории

## ЦЕЛЕВАЯ АУДИТОРИЯ
- Любители хип-хопа и рэпа
- Начинающие артисты ищущие биты
- Фанаты коллектива AWGEINMISE
- Музыкальные блогеры и медиа
